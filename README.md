# MisConn – Selected Code Samples

This repository contains selected Python modules from **MisConn**, an independently developed aviation data collection and processing platform.

The files are provided to demonstrate practical experience in Python programming, data extraction, validation, and API integration as part of my application to the Kiel Institute for the World Economy.

## Included Files

**`oooi_parser.py`**  
Parses operational flight timestamps, handles timezone normalization, and performs data validation and chronological consistency checks.

**`api.py`**  
Handles communication with the project's backend coordinator, including API requests, authentication, and error handling.

## Project Context

These files represent only a small portion of MisConn's broader architecture and are not intended to function independently.

Additional implementation details, technical documentation, and code samples can be provided upon request.
